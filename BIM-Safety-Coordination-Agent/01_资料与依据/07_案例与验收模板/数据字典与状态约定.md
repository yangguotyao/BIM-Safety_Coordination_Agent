# 数据字典与状态约定
唯一关联键使用 project_id + model_id + model_version + guid；不能仅依赖构件显示名称。task_id、zone_id、evidence_id、rule_id、case_id 分别唯一。样例主构件为 0FOHK4aT910wgskSbVHn0U，真实楼层 GUID 为 1Vhy2b2Mj9FRewx9CZZoux。
全部几何计算单位是米；IFC原始单位到米比例0.001。区域几何预览已经是世界坐标米，不得再次乘0.001。前端渲染可减局部原点，后端保存原坐标，点选时用GUID关联，不用屏幕坐标代替模型坐标。
时间使用含时区的ISO8601。演示固定检查时刻为2026-10-16T09:00:00+08:00，不能用系统今天过滤掉所有样例。活动有效要求开始时间≤检查时刻≤结束时间；证据默认要求同一任务时间窗、项目、模型版本和区域。整改后证据必须晚于人工记录的实施时刻，并与复核时刻匹配。
provenance 使用 real_source、derived_geometry、simulated、mixed 等明确值。示意图是“真实IFC几何派生加模拟观察”，不是现场照片或视觉检测输出。缺失人员、栏杆、坠落基准面信息均使用null/unknown，不用false或0填空。
Finding字段至少包括 finding_id、hazard、result、bim_guids、evidence_ids、rule_ids、checks、uncertainties。result取risk_candidate、no_issue_in_checked_items或needs_evidence。风险级别仅为演示策略输出，不宣称事故概率。
Control字段至少包括control_id、finding_id、action、owner、verification_requirements、status、version。责任人使用演示角色。Review包括decision、reviewer、reviewed_at、control_version和comment。Verification包括verified_at、evidence_ids、checks、reviewer_confirmed、result和remaining_risk。
AgentTrace记录run_id、node、tool、输入摘要、实际输出、时间、状态、错误及简短决策依据。禁止把固定动画伪装成执行记录，也不要求展示模型内部思维过程。
状态路径为draft→analyzing→pending_review→approved→rectifying→pending_verification→closed。分析证据不足转needs_evidence，补齐后重新分析；审批拒绝为rejected；复核不通过或关闭后条件变化转reopened。reopened可再次analyzing。没有人工批准不得进入rectifying，未提交新证据与人工复核不得closed。
