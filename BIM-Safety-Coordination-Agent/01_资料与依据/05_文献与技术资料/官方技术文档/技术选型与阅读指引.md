# 技术选型与阅读指引
Vue 3构建中文界面，Three.js显示后端提取的区域真实网格；后端采用FastAPI和Pydantic。IfcOpenShell负责IFC实体、楼层关系、单位和几何；LangGraph负责编排；SQLite保存案例、审批、复核和事件日志。
为避免首次浏览器直接解析394MB模型卡顿，首屏使用已提取的35个对象的区域几何预览，并清楚显示“区域预览”及范围。完整楼层构件索引可查询，选中未缓存对象时后端按需提取几何。web-ifc官方资料用于未来直接IFC加载参考，不作为首屏必需依赖。
默认检索可使用SQLite FTS5加中文字符二元组，基于核验过的条款种子返回top-k证据。FTS5不可用时用相同二元组BM25计算，清楚记录检索方法；接真实模型后将检索结果加入生成上下文。无需外部向量数据库、Embedding密钥或Revit才能演示。
官方HTML已归档并提取文字，网页样式/脚本可能依赖网络。优先阅读IfcOpenShell Python与几何处理、LangGraph概览、FastAPI教程、Vue介绍。代码示例以当前官方API和实际安装版本为准，交付时锁定能通过测试的依赖版本。
