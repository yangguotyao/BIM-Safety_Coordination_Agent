## 1. 最快启动

### macOS（访达）

1. 双击根目录的 **`启动网站.command`**。
2. 终端会创建/复用虚拟环境并启动服务，浏览器自动打开 **http://127.0.0.1:8000**。
3. 停止：双击 **`停止网站.command`**，或在终端按 `Ctrl+C`。

### 命令行

```bash
cd 02_网站源码
./scripts/start.sh
# 打开 http://127.0.0.1:8000
```

要求：macOS/Linux + Python 3.10+；首次安装依赖需要网络。前端构建产物已包含在 `02_网站源码/frontend/dist`，无需 Node 即可运行；若要重新构建，需要 Node 20+。

端口冲突时：

```bash
PORT=8001 ./scripts/start.sh
```

### 1.1 分享给别人（局域网）

`http://127.0.0.1:8000` 里的 `127.0.0.1` 是**回环地址**，只指向访问者自己的电脑。把它发给别人，别人的浏览器会去找“他自己的 8000 端口”，所以一定打不开。

同一 Wi-Fi / 热点下分享：

1. 先停止本机模式：双击 `停止网站.command`。
2. 双击 **`启动网站_局域网.command`**。
3. 把终端显示的地址发给对方，例如：`http://192.168.43.21:8000`。
4. 对方必须与你在**同一 Wi-Fi/热点**；如果路由器开启了 AP 隔离/访客网络隔离，设备之间仍然不能互访。
5. macOS 防火墙若开启，需要允许 Python 接收入站连接。

局域网 IP 可能随网络变化，可在终端运行 `ipconfig getifaddr en0` 查看当前值。

> 当前包没有登录/权限系统，且提供“重置演示数据”和上传接口。**只建议在可信局域网内临时分享**；不要直接把 8000 端口映射到公网。若要发给不在同一网络的人，需要 Cloudflare Tunnel、Tailscale、ngrok 或部署到云服务器，并先加访问控制。

## 2. 五分钟演示路线

1. **总览**：看案例定位、真实/模拟边界与六类职责工作流。
2. **打开预置案例**：`L05 板边安全检查演示（预置）` → 点击 **开始分析**，等待 Agent 写入 trace。
3. 在 **概览** 看 Finding、检查项、适用条款、不确定性与候选控制措施。
4. 在 **审核与措施** 由“演示安全员”批准；在 **实施与复核** 记录“演示机电班组”的模拟实施。
5. 在 **证据** 追加 `EV-010`（实施后防护已补充），回到 **实施与复核** 执行复核 → 案例关闭。
6. 关闭后追加 `EV-011`（条件变化，防护撤除）→ **保留历史并重新打开** → 状态变为 `reopened`。
7. 打开 **Agent 工作流** 查看 10 个图节点 / 11 条实际 trace 事件。
8. 打开 **验收实验室** → 运行全部 12 项 → 12/12。

> 所有现场观察均为模拟；证据图是“真实 IFC 几何派生 + 模拟标记”，不是现场照片。页面与导出文件持续标注这一边界。

## 6. 技术栈与关键设计

- 前端：Vue 3.5 + TypeScript + Vite 7 + Three.js 0.186。
- 后端：FastAPI + Pydantic v2 + LangGraph + SQLite（WAL/外键/FTS5）+ IfcOpenShell 0.9。
- 存储：`02_网站源码/backend/runtime/app.db`；原始资料只读。
- 端口：前端开发 5173；生产统一 8000；Vite 代理 `/api`。
- 默认 `DEMO_MODE=true`，无密钥完成全部 12 项验收。
- 真实模型模式：显式配置 `MODEL_BASE_URL / MODEL_API_KEY / MODEL_NAME`；配置不完整返回 503，不静默降级；输出经 Pydantic 与引用白名单校验。
- 状态机：`draft → analyzing → pending_review → approved → rectifying → pending_verification → closed`，分支 `needs_evidence / rejected / reopened`。
- 乐观锁：`expected_case_version`；控制措施版本递增；旧审批不能覆盖新方案。

## 10. 故障排查

| 现象 | 处理 |
|---|---|
| 端口 8000 被占用 | `PORT=8001 ./scripts/start.sh`；或停止占用进程 |
| 前端空白 | 确认 `frontend/dist/index.html` 存在；或 `npm run build` |
| 三维视图不可用 | 浏览器需支持 WebGL；更新 Chrome/Safari；关闭限制 WebGL 的扩展 |
| IfcOpenShell 首次按需提取很慢 | 376 MB 原始 IFC 首次打开约 10–25 秒；之后有 runtime 网格缓存 |
| 数据库损坏/想重来 | `curl -X POST .../api/demo/reset`，只重置 runtime |
| 真实模型模式报 503 | 检查 `MODEL_BASE_URL / MODEL_API_KEY / MODEL_NAME` 三项是否齐全 |
