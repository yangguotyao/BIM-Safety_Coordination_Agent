## 偏差与处理

1. **目录命名**：任务书写“demo 子目录”，交付包为清晰分层使用 `02_网站源码/`，并保留根目录 `demo -> 02_网站源码` 符号链接。`demo/` 路径可直接执行启动脚本。功能、路径解析与运行方式不受影响。
2. **Agent 节点数**：执行计划初稿写 8 个执行节点；实现增加 `LLM 归纳` 与 `Verification · 计划`，形成 10 个图节点、11 条 trace 事件，覆盖六类职责并保留真实模型归纳层。计划文档已同步修正。
3. **无密钥模式**：演示模式的 LLM 归纳用确定性模板，UI 标注“演示模型输出”；不调用任何收费 API。
4. **真实模型**：未提供可用密钥，因此未执行真实供应商调用；已验证“配置不完整 503”“调用失败 run failed + needs_evidence”“无静默降级”。真实调用代码与白名单校验已实现。
5. **S1 数据范围**：只预提取 35 个区域网格；其他构件按 GUID 懒加载。原始 IFC 完整保留。该范围在 UI 与 API 明确告知。
