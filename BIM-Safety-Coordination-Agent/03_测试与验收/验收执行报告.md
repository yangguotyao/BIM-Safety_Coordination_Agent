## 8. 无密钥与真实模型配置

### 8.1 默认无密钥

```text
GET /api/health
mode=demo, live_config_complete=false, db.ok=true

```

### 8.2 DEMO_MODE=false + 缺少配置（端口 8001）

```text
GET /api/health → {"ok": true, "mode": "live_incomplete", "live_config_complete": false}
POST /api/cases/CASE-S1-DEMO-001/analyze → HTTP 503
{"error":{"code":"live_model_config_incomplete", ...}}
```

### 8.3 DEMO_MODE=false + 假 URL/假密钥（端口 8002）

```text
GET /api/health → mode=live, live_config_complete=true
POST analyze → 202 queued
run → failed: "APIError: openai_compatible_chat 重试后失败"
case → needs_evidence, analysis_incomplete=1, findings=0
trace → LLM 归纳 retrying → failed；Safety Coordinator 失败
```

结论：

- 配置不完整返回可操作 503，不悄悄假装真实模式。
- 真实调用失败时 run failed、案例 needs_evidence，**不静默降级为演示结论**，也不自动判无风险。
- 未提供真实供应商密钥，因此没有伪造“真实调用成功”的结果。
