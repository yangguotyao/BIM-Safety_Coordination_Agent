# 整栋总览与页面排版验收

日期：2026-10-19。本地入口：http://127.0.0.1:8001/ 。

## 本轮改动

- 清理 BIM、业务总览、检查表单、案例、证据及规范等页面的介绍性小字、教程、重复脚注和实现说明。保留字段、状态、来源标签、错误及实际风险依据。
- 导航主项 16 px；主标题统一 32 px（窄屏 28 px），二级标题 22 px（窄屏 20 px）；常规按钮及表单 14 px。
- 业务总览改成待办指标与最近检查，直接提供继续检查和新建入口。
- 首页默认整栋 S1 建筑，选择“05 层 · 板边区域”切入局部模型，可返回建筑总览。窄屏首屏保留“进入05层检查区域”主按钮。
- 移除局部范围中重复的楼层选择器；当前检查范围仍为 05 层板边，避免展示其他尚无检查配置的楼层空场景。

## 整栋模型

原件：01_资料与依据/03_数据集/S1/bSDD_references_example.ifc 。

导出脚本：外层 scripts/build_building_preview.py 。构建产物：02_网站源码/frontend/public/bim/s1-building.glb 及 s1-building.json，随前端构建复制到 dist/bim。

- IFC 全部 16,372 个有表示构件导出成功，19 楼层。
- 1,480,776 个三角面，按楼层和类别合并为 154 批次。
- 18,099,708 bytes，约 18.1 MB；米制坐标、局部原点平移和 IFC → Web 三维轴变换。
- 符合顶点范围的批次使用 16 位索引，保留原有三角面与构件范围。
- GLB 用于整栋浏览；局部安全检查继续读取原 GUID 对应网格。总览按楼层选取，未声称每个合批构件都能在总览中逐一拾取。
