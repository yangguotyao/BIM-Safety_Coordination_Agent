## 新增测试覆盖

- 综合任务与栏杆高度专项使用不同的工具选择、检索词及风险检查项；未选择空间工具时 trace 如实记为 skipped。
- L04 等无数据范围进入澄清，不执行检查工具，不输出风险已排除。
- 同一 Case 跟进请求继承检查重点；不同 Case、不同本地会话的消息不混用；正文预算不超过 6,000 字节。
- 旧版本请求、进入授权实施阶段后的新任务、无效验收参数被拒绝。
- 批准后的验收快照参与复核；高度提高、1500 mm 单位转换、正文中“从 1.2 m 提高到 1.5 m”均不会沿用低值。
- 修改后的文字要求需要独立人工核验；重复措施 ID 无法覆盖另一项已批准要求。
- 模拟 HTTP 模型服务实际经过规划、说明和措施的序列化与校验；未知工具、越界区域、未经依据支持的措施数值及未知责任主体被拒绝。
- 模型调用失败保留明确失败状态；缺少模型配置时不修改原任务，不静默降级。
