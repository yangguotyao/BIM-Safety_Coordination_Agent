## 自动验证

后端完整测试 **51 passed**，包含原有 32 项和新增 19 项参数化场景；前端 `vue-tsc --noEmit` 与 Vite 生产构建通过。

新增校核覆盖：

- 同时同地触发；不同时间、不同平面范围、不同高度、仅边界相接均不误报。
- 缺责任主体或作业范围进入待补证；无时区的新增时间输入返回 422。
- 几何标注仅对本 Case 生效，构件不匹配返回 422。
- 冲突措施参与审批，批准后调整保留审批与原计划版本；未消除冲突复核重开，错时后可关闭。
- 原文引用不存在或高度缺数值/单位依据时拒绝保存候选。
- 无明确观察的文本要求澄清；修订保留历史；未来记录不进入本次 Safety State。
- 文本与确认观察冲突时保留两方；人工澄清后确认观察值保持不变。
- 任务规划输出不符合 Schema 时最多带校验反馈重试一次；持续失败仍拒绝，不回退成演示成功。
- JSON / Markdown 保留本轮新增数据。
