# 当前平台与原方案的差距核查

核查日期：2026-10-19。对象为本地 `BIM-Safety-Coordination-Agent/02_网站源码` 和 8000 端口实际运行服务。依据为外层原始 `BIM-Safety_Coordination_Agent_方案.docx`，重点核查第六步的 13 个 Case 步骤。本报告使用 height-work-agent-engineering 技能中的模型、工具、证据和规则边界审查方法。

结论：当前版本适合称为“真实 BIM 支撑的单场景规则流程原型”。它已有真实后端、持久化案例状态、几何查询、规范检索和审批复核闭环，但尚未完成原方案强调的“现场感知 → 多源安全状态 → LLM 协调工具 → 生成措施 → 新证据验证”的智能体演示。上一轮“可用版”的验收主要证明预置流程可运行，不能据此认定原方案全部完成。

## 三 已复现的具体缺陷

1. **非预览构件的几何范围错误。** `main.py:285` 与 `tools.py:106` 在没有预提取网格时回退到目标楼板包围盒。实际查询构件 `0BGfqjCPX70uXXKLeh5fKj`，属性接口返回范围从约 `[16.54,9.91,17.21]` 到 `[22.49,55.47,17.30]`；同 GUID 网格的真实范围却是 `[31.880004,47.605,16.83]` 到 `[32.070004,48.025,17.49]`。缺失几何应明确未知或读取对应缓存，不能借用另一构件数值。
2. **证据构件 GUID 不一致仍可匹配与复核通过。** `tools.py:288` 和 `:700` 比较项目、模型、版本、区域与时间等字段，未比较 `bim_guids`。在隔离的证据查找模拟中，只把合格 EV-010 的 GUID 换成另一个真实构件，复核仍返回 `pass_in_demo_scope`；检查时证据也仍标为 matched。该复现不修改演示数据库。界面所写“同构件证据”尚未成为完整的实际校验。
3. **规范生效时间未参与检索。** 将 `as_of` 设为 1900 年，检索仍返回数据库标为 2016/2023 年生效的条款。当前固定演示时刻可能掩盖问题，但不能据此宣称已完成规范时态适用性判断。
4. **从模型选择到 Case 缺少业务联动。** `StartInspectionView.vue:38` 仍提交固定模型、任务、区域且不读取当前三维选择；用户查看另一个构件不会自动改变检查对象。新增首页按钮只承担入口作用，这条业务链尚待实现。

复现脚本为本目录 `audit_repro.py`，结果为 `核查复现结果.json`。前三项分别通过只读接口、只读数据库与隔离工具输入核查，未改动已有 Case。此处是聚焦核查，不宣称已找出全部问题。

## 四 下一阶段应优先做什么

**先修结果可信度。** 为上述几何属性、构件与证据一致性、规范时间适用性建立失败测试，修复后验证未知数据不会被替代为真实值。已约定的重开后旧证据选择策略保持原范围，不将本次发现混同为该问题。

**接通一条真实模型参与的纵向 Case。** 沿用现有适配器和流程，使用明确配置的真实供应商，让任务规划、检索词、证据综合、补充信息请求和措施组织实际发生；保留确定性几何、阈值及审批。显示真实调用的模型名、耗时、调用结果与证据引用，不能只有一段模型生成说明。

**让 BIM 驱动任务。** 模型中的区域与构件选择进入 Case，统一 Task–Activity–Zone–GUID–Time 关联；对本案例需要的对象完善属性、邻接和距离查询。可继续采用按区域预处理和按需网格加载，不必一开始加载整个 395 MB IFC 或补齐全部楼层。

**补通现场证据输入。** 提供新图片的 VLM 结构化观察和人工确认，或先提供明确标注来源的人工观察录入。真实图片可以来自其他项目，补充任务、进度和责任可人工编制，但应在同一 Case 中明确位置、时间、GUID、来源及版本。合成图片用于演示时也要如实标记，不能把流程验证称为视觉准确率验证。

**再完善案例需要的进度与协调。** 如果演示多工种冲突，应准备至少两条与空间和时间关联的任务并计算重叠；如果最终仍演示单一临边检查，应优先把该检查的输入、工具、LLM 和再验证做完整。无需先扩展成多个独立 Agent 服务、长期记忆平台或实时传感系统。按既有约定，不新增施工方案审查子系统。

建议采用这样的验收：在网页选定真实 BIM 区域后，使用一份没有预先绑定结论的新证据和一段新任务描述；系统通过真实模型及实际工具形成决策包；改变构件、照片观察、时间或批准阈值时，结果与依据相应变化；审批实施后用新的证据重新计算并关闭或保留剩余风险。不能只以“12 个固定样例通过”作为整个方案完成的证据。
